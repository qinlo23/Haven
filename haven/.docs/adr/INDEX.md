## 状态约定

| 状态       | 含义                       |
| ---------- | -------------------------- |
| Proposed   | 方案已提出，待评审         |
| Accepted   | 通过评审，成为当前决策基线 |
| Deprecated | 被否决                     |
| Superseded | 被其他 ADR 取代            |

## 使用规则

- ADR 记录"为什么做这个决策"（背景、方案、权衡、后果），需求明细以 [requirements/](../requirements/) 为唯一来源。
- 已接受的 ADR 不做语义改写；如需变更，优先新增 ADR，或在文首加「历史归档」横幅并定点修正与现状直接冲突的条目（本仓库对 MDA 重写即按此处理）。
